# Bloor HMI

HMI project files and macro/configuration assets for the Bloor device interface.

## What This Repository Contains

- `Bolooric-HMI-eee.dpa` - HMI project file.
- `PB/` - project assets or generated HMI support files.
- `c1_rotation.txt` - rotation-related notes or macro content.
- `macro_home.txt` - home-screen or navigation macro content.

## Usage Notes

Open the HMI project in the matching vendor/editor software used for the device. Keep a backup before editing generated or vendor-specific files.

## Project Notes

If this repository stays public, document the HMI hardware model, editor version, communication protocol, and any device addresses that are safe to share.
